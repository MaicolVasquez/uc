# Proyecto : Unsa Conecta Portal Estudiantil

# Descripción de la aplicación web
- La página web "UNSA Conecta" es un portal estudiantil diseñado para facilitar la vida universitaria de la comunidad de la Universidad Nacional de San Agustín de Arequipa. De manera sencilla, funciona como una plataforma centralizada que ofrece cinco herramientas principales: un sistema para reportar o buscar objetos perdidos, un mapa interactivo para localizar facultades y servicios en los diferentes campus, un tablón de notificaciones con avisos importantes de la universidad, una sección de tutorías donde los estudiantes pueden enseñarse mutuamente, y una red social llamada "Punto Hueco" para organizar grupos de estudio, juegos o charlas durante las horas libres entre clases.
